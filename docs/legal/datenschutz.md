## Keine Cookies, keine Einbindung Dritter

Die ausgelieferten Seiten fordern **keine Ressourcen von fremden Servern** an.
Insbesondere werden keine Schriftarten von Google geladen — die Voreinstellung
des verwendeten Themes tut das, und sie wurde bewusst abgeschaltet, weil dabei
die IP-Adresse jedes Besuchers an Google übertragen würde, bevor die Seite
überhaupt sichtbar ist. Ebenso fragt die Seite nicht bei GitHub nach, wie
viele Sterne das Repository hat.

Dass dies so bleibt, wird bei jedem Bau automatisch geprüft: Ein Skript
durchsucht die erzeugten Seiten nach Anfragen an fremde Hosts und lässt den
Bau scheitern, wenn eine gefunden wird.

Links auf externe Seiten (etwa auf das Quellcode-Repository) sind gewöhnliche
Verweise. Sie werden erst aufgerufen, wenn Sie sie anklicken; erst dann
erfährt der dortige Anbieter etwas von Ihnen.
