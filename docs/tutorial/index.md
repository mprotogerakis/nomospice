# Tutorials

Four lessons that build on each other. Do them in order; each takes about ten minutes, and each ends with what you have learned.

1. **[Your first simulation](first-circuit.md)**: draw an RC low-pass, run a transient analysis, probe a voltage and a current, measure with cursors.
2. **[Frequency response](frequency-response.md)**: the same filter in an AC analysis: Bode plot, corner frequency, Nyquist plot, and two analyses in result tabs.
3. **[Sweeps and measurements](sweeps.md)**: run the filter for several capacitor values, measure each run, and simulate tolerances.
4. **[Your own block](blocks.md)**: turn the filter into a block with its own symbol and use it twice.

You need nomospice [installed](../install.md). The tutorials use the macOS keys; on Windows and Linux press ++ctrl++ where they say ++cmd++.

!!! info "As a video"
    Every tutorial can be turned into a narrated video: its pictures in order, each with the text that follows it spoken and shown as subtitles. See [How this documentation is made](../documentation.md).
